# data/

This directory is intentionally small. Large / upstream data is **not**
bundled with the repository — see `../NOTICE` for licensing reasons and
`../scripts/fetch_upstream_data.sh` for download instructions.

- `proteins/` — example target protein sequences (public amino-acid
  sequences; the codon-optimized CDS are generated by the pipeline).

## What is excluded and why

| Path (working copy) | Contents | Reason excluded |
|---|---|---|
| `data/t2/` | Ensembl CDS corpus (34MB), PaxDB — **excluded** (size + fetch script); wu2019 eLife coefficients (CC-BY) **included** in `data/t2/wu2019_elifescience/` | Size + provenance; fetch script + rebuild scripts provided |
| `data/t3_utr/` | GSE114002 MPRA, 431MB | GEO redistribution terms; fetch + `build_utr_table.py` |
| `data/t3_gemorna_si/` | Science SI xlsx (S1–S4) | Science/AAAS research-use terms; fetch from DOI |
| `data/t5/` | Top-K deliverable, refined pools, posthoc | Derived from GEMORNA/LinearDesign tool outputs (see NOTICE); regenerating from independent starts is a policy decision |
| `data/t4_cro/` | CRO shipping package | Commercial deliverable; contains pGL4.11 (Promega luc2)-derived Fluc example |
| `data/*_features.tsv` | Featurized upstream candidates | Derived from upstream tool outputs |
